Installing anaconda-channel-guide
==================

Installing `anaconda-channel-guide` from the main channel can be achieved by:

```
conda install anaconda-channel-guide
```

It is possible to list all of the versions of `anaconda-channel-guide` available on your platform with `conda`:

```
conda search anaconda-channel-guide
```
